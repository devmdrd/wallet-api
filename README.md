# Wallet API

A RESTful Wallet API built with Node.js, Express, Sequelize, and MySQL.

## Features

- User Registration
- JWT Authentication
- Wallet Management
- Add Funds
- Withdraw Funds
- Transfer Funds
- Transaction History
- Daily Transaction Limit
- Fraud Detection
- Multi-Currency Support
- API Rate Limiting

## Tech Stack

- Node.js
- Express.js
- MySQL
- Sequelize
- JWT
- bcrypt

## Installation

npm install

## Environment Variables

```
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=root
DB_NAME=wallet_db
JWT_SECRET=wallet_app_secret_key
```

## Run

npm run dev
